Minimal-Youtube

This repository is a signpost, not the extension itself. It holds a single Chrome Web Store link, contains no code of its own, and claims no credit for the extension it points to.

The linked extension, MinimalTube, offers a YouTube interface with the clutter taken away: fewer distractions around the video. This repo holds no feature list of its own, so nothing more specific is claimed here.

MinimalTube on the Chrome Web Store

The one door out of this house. The link is reproduced exactly as written in the repo; it was not re-verified in a browser in this pass, and nothing here installs or configures the extension.

Link care

If the link ever stops resolving, the fault is reported as an issue against this pointer repo, not against the extension. The drawn sheets for this repo live in its Minimal-Youtube-Visuals folder, and the source is the repo on GitHub.

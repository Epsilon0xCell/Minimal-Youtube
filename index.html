Minimal-Youtube

This repository is a seat in an emptied cinema, not the film itself. It began as a signpost: one Chrome Web Store link, and no claim to credit for the extension it points to. It has since added one small script of its own, kept in the repo beside the link.

The linked extension, MinimalTube, offers a YouTube interface with the clutter taken away: fewer distractions around the video. The repo's own userscript, minimal-youtube.user.js, does the same emptying locally in your browser: it hides the watch page sidebar and its recommendations, the comments, Shorts shelves and end screen cards, and lets the watch page use the width the sidebar gave up.

MinimalTube on the Chrome Web Store

The one lit aisle out of this cinema. The link is reproduced exactly as written in the repo; it was not re-verified in a browser in this pass, and nothing here installs or configures the extension.

Link care

If the link ever stops resolving, the fault is reported as an issue against this pointer repo, not against the extension. The drawn sheets for this repo live in its Minimal-Youtube-Visuals folder, and the source is the repo on GitHub.
